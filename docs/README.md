# docs/

This folder is for **local-only** author / agent operating notes on the machine that maintains the blog.

- Contents under `docs/` are **gitignored** (except this file).
- They do **not** appear on the public website.
- They are **not** pushed to GitHub, so visitors cannot browse them in the public repo.

If you are the site owner and the notes are missing after a fresh clone, recreate them from your own backup or ask your agent to rebuild `blog-publishing-notes.md` / `site-design-notes.md` from the current site structure.
